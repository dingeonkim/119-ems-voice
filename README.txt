119 환자정보 음성정리 PWA

중요: 이 앱은 file:// 로 직접 열면 Chrome에서 마이크가 차단될 수 있습니다.
GitHub Pages, Cloudflare Pages, Firebase Hosting 등 HTTPS 정적 호스팅에 업로드하세요.

Galaxy Tab:
1. Chrome에서 HTTPS 주소 접속
2. 마이크 권한 허용
3. Chrome 메뉴에서 '홈 화면에 추가' 또는 '앱 설치'
4. 이후 홈 화면 아이콘으로 실행

음성인식과 기본 정보 분류는 브라우저에서 처리하며 별도 AI API로 환자정보를 전송하지 않습니다.
실제 환자정보 사용 시 소속 기관 규정을 준수하세요.
